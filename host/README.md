# host

Exercises that are built and run on a PC (Linux), not on the board. They cover the C and systems fundamentals behind the embedded work in `stm32/`: build tools, data representation, debugging and memory analysis.

## Requirements

- GCC
- Make
- CMake (3.16 or later)

## Contents

| Folder | Topic |
|---|---|
| `01-gcc-make-cmake/` | Ring buffer in C with unit tests, built with GCC by hand, Make and CMake |

Each folder has its own README with build and run instructions.
