# embedded-systems-learning

Documented process of learning embedded systems, from C and systems fundamentals on the PC to bare-metal programming on an STM32 Nucleo-F446RE board.

*Versión en español más abajo.*

## Structure

- `host/` — Exercises built and run on the PC (build tools, data representation, debugging)
  - `01-gcc-make-cmake/` — Ring buffer in C with unit tests, built with GCC, Make and CMake
- `stm32/` — Projects running on the Nucleo-F446RE
  - `00-blink/` — LED blink at register level, with its own startup code and linker script
  - `01-gpio-basics/` — GPIO basics
  - `02-i2c-mpu6050/` — I2C communication with the MPU6050
  - `03-sd-logging/` — SD card data logging
- `Drivers/` — ARM CMSIS and ST libraries (Git submodules)

## Cloning

ARM (CMSIS) and ST (STM32F4 device headers and HAL) libraries are included as Git submodules under `Drivers/`. To fetch them along with the repository:

```bash
git clone --recurse-submodules https://github.com/marioLP-eng/embedded-systems-learning.git
```

If you already cloned it without submodules and `Drivers/` is empty:

```bash
git submodule update --init
```

# embedded-systems-learning (español)

Proceso documentado de aprendizaje de sistemas embebidos, desde la base de C y sistemas en el PC hasta la programación bare-metal sobre una placa STM32 Nucleo-F446RE.

## Estructura

- `host/` — Ejercicios que se compilan y ejecutan en el PC (herramientas de compilación, representación de datos, depuración)
  - `01-gcc-make-cmake/` — Buffer circular en C con tests, compilado con GCC, Make y CMake
- `stm32/` — Proyectos que se ejecutan en la Nucleo-F446RE
  - `00-blink/` — Parpadeo de un LED a nivel de registros, con su propio código de arranque y linker script
  - `01-gpio-basics/` — Fundamentos de GPIO
  - `02-i2c-mpu6050/` — Comunicación I2C con el MPU6050
  - `03-sd-logging/` — Registro de datos en tarjeta SD
- `Drivers/` — Librerías CMSIS de ARM y de ST (submódulos de Git)

## Clonar el repositorio

Las librerías de ARM (CMSIS) y de ST (cabeceras del STM32F4 y HAL) están incluidas como submódulos de Git en la carpeta `Drivers/`. Para descargarlas junto con el repositorio:

```bash
git clone --recurse-submodules https://github.com/marioLP-eng/embedded-systems-learning.git
```

Si ya lo has clonado sin submódulos y la carpeta `Drivers/` está vacía:

```bash
git submodule update --init
```
